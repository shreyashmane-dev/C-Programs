# C Programs Repository

A comprehensive collection of C programming lab programs and exercises covering 1D arrays, 2D matrices, searching and sorting algorithms, character arrays (strings), and modular menu-driven systems.

## Folder Structure

### Day 3 Programs (`day3/`)
- **Fundamentals**
  - `hello.c`: Basic Hello World in C
  - `c1.c` - `c5.c`: Basic function calls and array traversals
- **1D Array Fundamentals**
  - `prog01_array_input_output.c`: Reading and printing array elements with indices
  - `prog02_array_sum_average.c`: Sum and floating-point average calculation
  - `prog03_largest_smallest.c`: Maximum and minimum elements
  - `prog04_linear_search.c`: Linear search with position tracking
  - `prog05_reverse_array.c`: In-place two-pointer array reversal
  - `prog06_count_even_odd.c`: Counting and separating even and odd numbers
  - `prog07_copy_array.c`: Copying elements from one array to another
  - `prog08_second_largest.c`: Single pass second-largest element lookup
- **Array Operations & Sorting**
  - `prog09_bubble_sort.c`: Bubble sort algorithm
  - `prog10_insert_element.c`: Inserting an element at a given position
  - `prog11_delete_element.c`: Deleting an element from a given position
  - `prog12_frequency_count.c`: Counting occurrence frequency of elements
- **2D Arrays & Matrices**
  - `prog13_matrix_input_print.c`: 2D matrix input and tabular display
  - `prog14_matrix_addition.c`: Matrix addition
  - `prog15_matrix_transpose.c`: Matrix transpose
  - `prog16_diagonal_sum.c`: Primary and secondary diagonal sums
- **Character Arrays & Algorithms**
  - `prog17_string_length_reverse.c`: String length and reversal without string library
  - `prog18_palindrome_check.c`: Palindrome check
  - `prog19_merge_sorted_arrays.c`: Merging two sorted arrays
  - `prog20_array_menu_operations.c`: Menu-driven array operations system

## How to Run
```bash
gcc day3/prog01_array_input_output.c -o prog01.exe
./prog01.exe
```
